## Repo

- Single Next.js 16 app (App Router), bootstrapped with create-next-app. Not a monorepo; there is no `pages/` directory — routes live in `app/`.
- Root page: `app/page.tsx`; root layout: `app/layout.tsx`; global styles: `app/globals.css`.
- UI components: shadcn/ui in `components/ui/` (style `base-nova`); `cn` helper re-exported from `lib/utils.ts` (`import { cn } from "@/lib/utils"`).
- Path alias `@/*` resolves to the repo root (`tsconfig.json` `paths`).

## Developer commands

- `npm run dev` — dev server on http://localhost:3000 (Turbopack).
- `npm run build` — production build (includes TypeScript typechecking).
- `npm run start` — production server; run `build` first.
- `npm run lint` — ESLint (flat config in `eslint.config.mjs`, extends `eslint-config-next`).
- No test script and no test runner are configured; there are no test files.

## Verification flow

`npm run lint && npm run build` — lint first, then build (build typechecks). For a typecheck-only pass run `npx tsc --noEmit` (`strict: true`, `noEmit`).

## Environment

- `.env*` is gitignored: local env files are opt-in and never committed. Create `.env.local` locally if needed.
- Do not commit or edit generated artifacts: `.next/`, `out/`, `build/`, `node_modules/`, `next-env.d.ts`, `*.tsbuildinfo`. `next-env.d.ts` is regenerated automatically.
